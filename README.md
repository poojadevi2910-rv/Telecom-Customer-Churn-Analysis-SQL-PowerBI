# Telecom Customer Churn Analysis | SQL Server & Power BI

## Project Overview
This end-to-end data analytics project focuses on analyzing telecom customer churn to identify key factors associated with customer attrition, understand customer behavior, and provide actionable business recommendations to improve customer retention.

The project uses **SQL Server** for data exploration and analysis and **Power BI** for interactive dashboard development and visualization.

## Business Objectives
- Identify customer segments with higher churn rates.
- Analyze the relationship between contract types and customer churn.
- Evaluate churn patterns across internet services and payment methods.
- Understand the association between additional services and customer retention.
- Identify opportunities to reduce customer attrition and potential recurring revenue loss.

## Tools & Technologies
- **SQL Server:** Data exploration, data quality checks, querying, aggregations and analytical queries.
- **Power BI:** Interactive dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Measures and churn rate calculations.
- **CSV:** Dataset source files.

## Project Workflow

### 1. Data Exploration & Analysis – SQL Server
- Imported the telecom customer dataset into SQL Server.
- Explored table structures, columns, and data types.
- Performed data quality checks to identify missing values and potential inconsistencies.
- Used SQL queries to analyze customer churn patterns.
- Applied filtering, grouping, aggregations to derive business insights.

### 2. Data Transformation & Visualization – Power BI
- Imported data into Power BI.
- Cleaned and transformed data using Power Query.
- Created data models and established relationships between tables where appropriate.
- Developed DAX measures to calculate customer churn metrics.
- Designed interactive charts, KPI cards, and slicers.
- Enabled dynamic analysis across customer segments.

### 3. Key Analysis Performed
- Churn rate analysis by contract type.
- Churn analysis across internet service categories.
- Payment method analysis and churn distribution.
- Analysis of additional services, including:
  - Online Security
  - Tech Support
  - Online Backup
  - Device Protection
- Combined customer segment analysis using interactive slicers.

## Key Findings
- Month-to-month contract customers exhibited higher churn rates.
- Fiber optic customers showed higher churn patterns.
- Electronic check represented a significant proportion of churned customers.
- Customers without additional security and support services showed higher churn patterns.

## Business Recommendations
- Encourage customers to adopt long-term contracts through suitable retention offers.
- Consider offering free trials of value-added services such as Online Security and Tech Support.
- Investigate customer experience issues associated with Fiber optic services.
- Review payment-related customer experience and explore alternative payment options.
- Develop targeted retention strategies for customer segments with higher churn rates.
